本システムでは、パソコンで御利用いただく方向けに２種類の画面をご用意しております。
  • 施設予約システム＜多機能版＞画面では、いつも本システムをご利用の方で、比較的パソコンの操作に慣れた方向けに より使いやすい機能をご用意した画面になります。
  • 従来からの施設予約システムの画面を利用したい方、あるいは対話型の簡単な操作の画面を利用したい方は、＜簡易版＞をご利用ください。
（スマートフォンで御利用いただく場合は、ページ末尾をご覧ください。）

■本システムを利用するには、以下のパソコン環境が必要です。

ＯＳ
（日本語版のみ対応）
  • Microsoft Windows 10
  • Microsoft Windows 11
  • macOS Sierra、High Sierra、Mojave、Catalina
ブラウザ
  • Microsoft Edge（最新版）
  • Firefox（最新版）
  • Opera（最新版）
  • Google Chrome（最新版）
  • Safari（最新版）(macOS版のみ)
画面解像度（推奨） 1024*768以上（簡易版、多機能版）、800*600（簡易版）
その他
  • TLS1.2以上の暗号化通信に対応していること。
  • SHA-2証明書に対応していること。
  • このシステムは一部の画面にJavaScript（ジャバスクリプト）を使用しています。ご利用の際は「JavaScriptを有効」に設定して下さい。
    （携帯電話各機種の「TLS1.2以上の暗号化通信」と「SHA-2証明書」への対応状況については、各携帯電話事業者の情報を御参照ください。）


＜Windows 10／Windows 11 使用上の注意点＞
  • 新しく使用可能な文字（JIS第３水準、第４水準漢字）が追加されていますが、これらの文字は使用しないでください（代替文字を使用してください）。
  • 字形が変更された文字があります。他のＯＳで画面での表示が異なる場合がありますのでご注意ください。
＜Microsoft Edge 使用上の注意点＞
  • 「タブブラウジング機能」は使用しないでください。新しくサイトをご利用になる場合は、新規にウィンドウを開いてご利用ください。
■ブラウザの「戻る」「進む」機能を使用すると、その後の処理の動作は保証されません。
  • ブラウザの「戻る」「進む」機能を使用すると、「ページの有効期限切れ」という警告画面が表示さますので、再びメニュー画面から操作しなおしてください。

■スマートフォン版機能は、https://www.e-shisetsu.e-aichi.jp/sp/　から御利用いただけます。
　スマートフォンは「TLS1.2」以上の暗号化通信と「SHA-2証明書」に対応しているAndroid 7以降又はiOS9以降の機種を御利用ください。

■携帯電話版機能は、https://www.e-shisetsu.e-aichi.jp/keitai/　から御利用いただけます。
　携帯電話は「TLS1.2」以上の暗号化通信と「SHA-2証明書」に対応している機種を御利用ください。
  • 従来型の携帯電話（フィーチャーフォン、いわゆるガラケー）は、セキュリティ強化対応により2018年6月18日から使用できなくなりました。
  • 対応している携帯電話、スマートフォン（Android 7以降又はiOS9以降）又はパソコンから御利用くださるようお願いいたします。
    　（各機種の対応状況については、各携帯電話事業者の情報を御参照ください。）
